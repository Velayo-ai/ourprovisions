Behaviour notes for build

  • No data change. meals.instructions stays free text. Read mode is a pure render: split on a line that begins with digits + period, trim, drop empties. Text that doesn't match the numbered pattern (someone typed a paragraph) renders as a single unnumbered step — never fails.
  • Mode state: one useState('read' | 'edit') in the meal sheet. Default edit when instructions are empty, read when they exist, and read after a Galley result lands.
  • Galley provenance ("From the galley" eyebrow) is client-side session state for Phase A — set when the Galley fills the sheet, cleared on cancel. Not persisted. Persisting a source column is a Phase B question alongside serves/time/difficulty.
  • Galley block visibility: shown in idle; replaced by thinking state during the request; collapsed to the "Ask the galley again" link once a result lands; dimmed while editing steps.
  • Thinking state replaces both ingredient chips and steps with skeletons of the same height, so the sheet doesn't jump on arrival. "Never mind" aborts the fetch (AbortController) and restores the previous field values.
  • Copy: "Instructions" → "Steps" in label and field. Button verbs: Ask the galley / Edit steps / Done / Never mind / Save meal.
  • Deferred to Phase B: serves / time / difficulty (migration + prompt contract), step titles, real meal photo (earned via plate photo, never stock).
