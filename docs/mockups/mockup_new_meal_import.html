What this mockup decides

  • No separate arrival sheet. Every outside recipe fills the New Meal form, the contract Ask AI already set (“filled into the fields above… replaces what's there now”).
  • Order: Type it → OR → Ask AI → OR → Bring a recipe. Bring is one row The row expands only after a pick.
  • Photo takes up to 4 screenshots, read as one recipe in the chosen order. A visible creator handle fills From as “@handle on Instagram”.
  • One door in play at a time: hand-building hides both doors; picking photos hides Ask AI; a filled form shows no doors, only Start over.
  • Additions to the form, only when a recipe arrived: the banner with Start over, the From field, and New item / Check this chips. A hand-built meal looks exactly as it does today.
  • No teal — nothing here is a completion.
  • Ask AI block unchanged — label, mic, fine print and the Ask the Galley button stay as shipped (reviewed 10-07; both alternatives declined).
  • Open: eyebrow for pasted text (“Filled from what you pasted”?); the sharing button wording (frame 6).
