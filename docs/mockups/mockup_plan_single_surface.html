What this changes in SPEC_meal_planning_v1.md: the two sub-tabs (Meals | This Week) become one surface — canvas above, library below. The lens slot Board | Days is decided now. Board ships in v1 with a fixed-height board; Days is the v2 days toggle already deferred, but now it has a home and an "Any day" row so lens switching never loses a meal. The model is untouched: in-week is still derived from unbought ingredients, add = plan = shop, remove zeroes unbought only. Long-press-to-drag is additive — the Add button is always the accessible path. New open question for the build: Board needs x/y per card, Days needs a day per meal — one meal_placements-style row per (household, meal) holding both would serve both lenses and the "shared arrangement" requirement at once.
